在线进度只保存在当前浏览器，并支持脱敏 JSON 导入导出；下方 Markdown 清单仍是适合提交到个人
学习分支的离线模板，两者不会自动同步。自动验收可在仓库根运行 `npm run learn:day -- NN`，
结果写入对应的 `learning-evidence/day-NN/report.json`。

复制这份文件作为个人学习记录。只有当天完成 120 分钟主动学习、动手实验、独立任务和验收证据后才勾选。等待安装、构建、部署和 CI 的空闲时间不能计入。

## 使用规则

- `[ ]` 表示未完成或待补，`[x]` 表示证据已验收。
- 每一项都填写日期和证据位置；只看完文档不能勾选。
- 分支建议使用 `learn/day-NN-topic`，提交 ID 至少记录一个。
- 未通过的 Day 保持未勾选，在“补课队列”登记，不跳过依赖继续累计。
- 截图和日志必须删除 Cookie、token、连接串、私有 URL 与个人信息。

```markdown
- 等待时间：___ 分钟（不计入主动学习）

#### 今天的目标与预测

- 我要解决：

- 我这样预测的原因：

#### 源码与改动

- 阅读的关键文件：
- 修改的文件：
- 数据/事件流：

#### 动手实验

- 输入或操作：
- 期望：
- 实际：
- 第一处差异：

#### 独立任务

- 关闭步骤后完成了什么：
- 哪一部分仍需要提示：

#### 错误与调试

- 完整错误摘要：
- 假设：
- 排除证据：
- 根因与修复：

#### 验收证据

- 测试/类型/构建：
- 截图/Network/trace：
- 提交：
- 已确认脱敏：是 / 否

#### 用自己的话解释

1. 数据从哪里来？
2. 代码为什么这样工作？
3. 哪个证据能证明？
4. 还剩什么风险？

#### 明天开始前

- 未解决问题：
- 下一步最小动作：
```
