# 00–12 知识专题索引

这一目录是按主题组织的知识讲义，回答“这个概念是什么、项目在哪里使用、怎样继续实验”。
它会链接到 TypeScript、后端和参考资料专题，避免重复相同内容。

::: tip 第一次学习前端
请从 [91 天、182 小时课程](../90-days/)开始。日课会告诉你每天读哪一节、追踪哪段
源码、完成什么独立任务，以及怎样证明自己真的掌握；本页不是三个月课表。
:::

复习或查漏补缺时，推荐一次只学一个专题，并使用独立 Git 分支保存实验。
